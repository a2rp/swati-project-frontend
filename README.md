# Swati Frontend

A responsive React frontend for account access and protected title search, connected to a local API service.

## Features

- Lazy-loaded Home, Login, and Search routes
- Token-based login state stored in local storage
- Protected search flow with API result cards
- Responsive fixed header with mobile navigation and floating go-to-top control
- Loading, validation, and API error states
- Icon-only social and support links in the footer
- Local logo, favicon, preview, and loading assets


## Future improvements

- Connect the frontend to a production API and expand search filters.

## Tech stack

React, React Router, Material UI, Sass modules, Axios, and React Icons.

## Run locally

~~~
npm install
npm start
~~~

The login and search screens expect the API service at http://localhost:1198.

## Deployment

Live site: [a2rp.github.io/swati-project-frontend](https://a2rp.github.io/swati-project-frontend/)

Build and deploy:

~~~
npm run lint
npm run build
npm run deploy
~~~
